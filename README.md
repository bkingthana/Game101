# The Magic Farmcare

เกมวางแผนการเกษตรแบบ Pixel art เล่นผ่าน browser บนมือถือ ไม่ต้องติดตั้ง
นำเสนอโดย ธนาพันธ์ ฟาร์มแคร์

**เล่นออนไลน์:** https://the-magic-farmcare.vercel.app

## วิธีเล่น

- เริ่มด้วยทุน 20,000 บาท เล่น 1 ปี (3 ฤดู: ฝน / หนาว / ร้อน) จบในราว 5 นาที
- ฟาร์มมี 4 แปลง ดินและภูมิประเทศต่างกัน (ที่ลุ่ม, ที่ดอน, ดินร่วน, ริมโขงดินตะกอน) ฉากเป็นแม่น้ำโขง ทิวเขาฝั่งลาว และพระธาตุพนม แบบ อ.ธาตุพนม จ.นครพนม (แตะพระธาตุแล้วมีเสียงระฆังและข้อความ) มีควายเล็มหญ้ากับนกกระยาง ลุงพันธ์เดินดูแปลง ผักตบชวาลอยในแม่น้ำ
- หน้าแรกเป็นภาพปก Pixel art แบบเกมยุค 90: แปลงผักและนาข้าวลอยกลางฟ้า มีเถียงนาและโอ่งน้ำ เมฆลอยผ่าน ลมพัดใบพืช (`js/cover.js`)
- เวลาในฉากฟาร์มเดินตามช่วงของฤดู: เตรียมปลูก = เช้า (พระอาทิตย์ขึ้นจากฝั่งลาว แสงทองบนแม่น้ำโขง), ดูแล = กลางวัน, เก็บเกี่ยว = เย็น (พระอาทิตย์ตก)
- ตอนเก็บเกี่ยวฤดูฝน (ตรงกับออกพรรษา) ฉากเป็นกลางคืน มีพระจันทร์เต็มดวงและไหลเรือไฟบนแม่น้ำโขง
- หน้าจบเกมมีถ้วยหรือเหรียญตามยศ ลุงพันธ์ให้คำแนะนำ และมีพลุถ้าได้ 3 ดาว
- แปลงริมโขงสูบน้ำได้ถูก แต่หน้าฝนน้ำโขงขึ้นท่วมพืชที่ไม่ทนน้ำ (ผักบุ้งและข้าวทนได้)
- 1 ฤดูมี 3 ช่วง
  1. **เตรียมปลูก**: ดูพยากรณ์อากาศ (แม่นราว 70%) เลือกพืช (ข้าว / ข้าวโพดเลี้ยงสัตว์ / หอมแดง / ผักบุ้ง / คะน้า / ผักชีลาว / พักดินหว่านปอเทือง / ปล่อยว่าง) ปุ๋ยรองพื้น (9 สูตร เลือกตามธาตุที่ดินขาด) การป้องกันโรคตั้งแต่ปลูก และปูนโดโลไมท์ถ้าดินเริ่มเปรี้ยว
  2. **ดูแล**: เจออากาศจริง (สูบน้ำตอนแล้ง ระบายน้ำตอนน้ำท่วม) แมลง โรค วัชพืช ต้องเลือกยาให้ถูกจาก 4 ตัวเลือก และใส่ปุ๋ยแต่งหน้าได้แปลงละ 1 ครั้ง
  3. **เก็บเกี่ยว**: ขายผลผลิต ดูสรุปว่าอะไรทำให้ผลผลิตลดลง (ธาตุที่ขาด ดินเปรี้ยว อากาศ ศัตรูพืช)
- ลุงพันธ์จากธนาพันธ์ ฟาร์มแคร์ สอนเล่นทีละขั้น ข้ามได้ และเรียกให้สอนใหม่ได้จากเมนู (เมนูมีเปิด/ปิดเพลงและเสียงเอฟเฟกต์ และวิธีเล่น)
- ปลูกพืชเดิมซ้ำแปลงเดิม หรือใส่ไนโตรเจนมากเกิน (เกิน 1.5 เท่าที่พืชต้องการ) โรคและแมลงเกิดง่ายขึ้น
- ผักกินใบที่ไม่ใช้ยาเคมี หรือใช้ชีวภัณฑ์ (เชื้อบีที ไตรโคเดอร์มา) ขายเป็นผักปลอดภัย ได้ราคาเพิ่ม 15%
- ป้องกันโรคตั้งแต่ปลูก (เลือกได้เฉพาะพืชที่มีโรคนั้น):
  - **คลุกเมล็ดด้วยสารกันรา** 100 บาท: ลดโอกาสโรคเน่าคอดิน 80% (ผักชีลาว), ราน้ำค้างข้าวโพด 70%
  - **ไตรโคเดอร์มาผสมดินขี้จอก** 250 บาท: ลดโอกาสโรคเน่าคอดิน 60% และโรครากเน่าโคนเน่า 60% (ผักชีลาว)
  - โรคในดิน (เน่าคอดิน, รากเน่าโคนเน่า) รักษาตอนเป็นแล้วได้ผลแค่ 60% ราน้ำค้างข้าวโพดได้ 70% โรคอื่นได้ 90% แปลงที่ชื้น (ที่ลุ่ม, ริมโขง) เกิดโรคในดินบ่อยกว่า
  - คลุกเมล็ดไม่ทำให้เสียสิทธิ์ราคาผักปลอดภัย (ใช้ก่อนปลูก ห่างจากวันเก็บเกี่ยว)
- ได้ดาวตามเงินตอนจบ: 1 ดาว 45,000 / 2 ดาว 55,000 / 3 ดาว 65,000 บาท
- ความยาวเกมและเป้าดาวตั้งได้ที่ `MF.CONFIG` ใน `js/data.js` (`years`, `stars`)
- ถ้าเงินเหลือไม่ถึง 1,000 บาทตอนเริ่มฤดู จะล้มละลาย
- เกมบันทึกอัตโนมัติในเครื่อง ปิดแล้วกลับมาเล่นต่อได้
- รองรับจอหลายขนาด: มือถือ (กว้างไม่ถึง 640px) เหมือนเดิม; จอกว้างแนวตั้ง เช่น Galaxy Fold ตอนกาง หรือแท็บเล็ต ฉากอยู่ซ้าย ขั้นตอนและปุ่มอยู่ขวา แปลงและการ์ดเรียง 2 คอลัมน์; จอแนวนอนแผงข้อมูลอยู่ขวาเต็มความสูง (ทั้งหมดอยู่ใน media query ท้าย `css/style.css`)
- หน้าจบเกมมีปุ่ม **แชร์รูปผลคะแนน** (การ์ดยศ 1080x1350 แต่ละยศหน้าตาต่างกัน: 3 ดาวโล่ทองพื้นเข้ม มงกุฎ ช่อมะกอก ประกาย / 2 ดาวโล่เงิน / 1 ดาวโล่ทองแดง / 0 ดาวโล่เขียว / ล้มละลายโล่เทา ด้านบนเป็นภาพพระธาตุพนมกับโลโก้ ในโล่เป็นถ้วยรางวัลสำหรับยศสูงสุด ยศอื่นเป็นพืชที่ผู้เล่นปลูกได้มากที่สุด มีเงินสุดท้าย สถิติผลผลิตทั้งปี ยาที่เลือกถูก กำไรทั้งปี และ footer ตาม CI ธนาพันธ์ ฟอนต์ Kanit tagline "เคียงข้างทุกการเติบโต" เบอร์โทร LINE Facebook แถบทุ่งนา เปิดเมนูแชร์ของมือถือ ถ้าไม่มีจะดาวน์โหลดรูปและคัดลอกข้อความพร้อมลิงก์ให้) และปุ่ม **ชวนเพื่อนเล่นทาง LINE**
- เวลาส่งลิงก์เกมใน LINE หรือ Facebook จะขึ้นรูปพรีวิว `img/og-image.png`

## ตั้งค่าที่ BK แก้เองได้ (`js/data.js` ใน `MF.CONFIG`)

- `contact`: ช่องทางติดต่อร้าน `lineId` / `line` (LINE OA @thanapun), `phone`, `map` (ลิงก์ Google Maps) ใส่อย่างน้อย 1 อย่าง หน้าจบเกมจะขึ้นกล่อง "ปรึกษาเรื่องปุ๋ย ยา และเมล็ดพันธุ์" ถ้าว่างทั้งหมดกล่องจะไม่แสดง
- `shareUrl`: ลิงก์เกมที่พิมพ์บนการ์ดแชร์ (ถ้าเปลี่ยนเป็นโดเมนบริษัท ให้แก้ที่นี่ และใน meta `og:` ของ `index.html`)

## นับจำนวนคนเล่น (Vercel Web Analytics)

- เว็บโหลดสคริปต์นับผู้เข้าชมของ Vercel (ไม่ใช้ cookie ไม่เก็บข้อมูลส่วนตัว) เฉพาะบนเว็บจริง ไม่โหลดตอนเปิดไฟล์ในเครื่องหรือในลิงก์ claude.ai
- ต้องเปิดใช้ครั้งเดียวใน Vercel: โปรเจกต์ the-magic-farmcare > แท็บ Analytics > Enable
- นับเหตุการณ์ `game_start`, `game_end` (จำนวนดาว), `share` (แชร์รูปหรือ LINE) เหตุการณ์แบบกำหนดเองดูได้เฉพาะแพ็กเกจ Pro ของ Vercel ส่วนจำนวนผู้เข้าชมดูได้ทุกแพ็กเกจ

## เปิดเล่นในเครื่อง

ดับเบิลคลิก `index.html` เปิดด้วย Chrome / Safari ได้เลย (ต้องต่อเน็ตเพื่อโหลด font)

## การอัปเดตเว็บ (Vercel)

- เว็บอยู่ที่โปรเจกต์ `the-magic-farmcare` ใน Vercel ของ BK เป็นไฟล์ static ที่ root ของ repo ไม่มีขั้นตอน build
- ตอนนี้ยังไม่ได้ติดตั้ง Vercel GitHub app การ push code จึง **ไม่** อัปเดตเว็บอัตโนมัติ ต้องสั่ง deploy ใหม่จาก branch นี้ทุกครั้ง (ให้ Claude ทำผ่าน Vercel connector ได้)
- ถ้าอยากให้อัปเดตเองทุกครั้งที่ push: ติดตั้ง Vercel app บน GitHub แล้วเชื่อมโปรเจกต์กับ repo `bkingthana/Game101` ในหน้า Settings > Git ของโปรเจกต์
- `.vercelignore` กันไม่ให้ไฟล์ที่ไม่ใช่ตัวเว็บขึ้นเว็บ: `scripts/`, `dist/`, `screenshots/`, `README.md`, `package.json` (เว็บจริงมีแค่ `index.html`, `css/`, `js/`, `img/`)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ |
| `css/style.css` | หน้าตาและสี |
| `js/data.js` | ข้อมูลเกมทั้งหมด: พืช ปุ๋ย ยา ศัตรูพืช ราคา สภาพอากาศ บทพูดลุงพันธ์ **แก้ตัวเลขสมดุลเกมที่นี่** |
| `js/engine.js` | กติกาและการคำนวณผลผลิต (ไม่เกี่ยวกับหน้าจอ) |
| `js/sprites.js` | ภาพ Pixel art ทั้งหมด วาดเป็นตัวอักษรทีละจุด |
| `js/scene.js` | ฉากฟาร์มเคลื่อนไหว (ป้ายธนาพันธ์ ฟาร์มแคร์ ต้นมะพร้าว พระธาตุพนม แม่น้ำโขง ควาย นกกระยาง ฝน หมอก คืนไหลเรือไฟ) |
| `js/audio.js` | เพลงพื้นหลังช้าๆ บรรยากาศริมโขงยามเย็น 72 BPM ลายสุดสะแนน: แคนเป่าเสียงยืน (G กับ D) โหวดและแคนสลับกันนำทำนอง พิณดีดช้าๆ โปงลางตอบ ฉิ่ง กลองเบาๆ ฆ้องวัด เสียงน้ำโขงและนก และเสียงเอฟเฟกต์ 8-bit สร้างด้วย Web Audio ใน code ทั้งหมด ไม่มีไฟล์เสียง |
| `js/ui.js` | หน้าจอ ปุ่ม บทสอน การบันทึกเกม หน้าจบเกม การแชร์ และการนับผู้เล่น |
| `js/main.js` | จุดเริ่มเกม: เรียก `MF.ui.boot` และถ้าเปิดเป็น claude.ai artifact จะพาเกมที่เล่นค้างข้ามการอัปเดตหน้า |
| `img/logo-thanapun-color.png` | โลโก้สีเต็มสำหรับพื้นขาว (จาก logo2 PNG ใน Drive) ใช้บนการ์ดแชร์และรูปพรีวิว |
| `img/logo-thanapun-dark.png` | โลโก้ธนาพันธ์ ฟาร์มแคร์ แบบตัวหนังสือสีขาวสำหรับพื้นเข้ม (ตาม color guide) |
| `scripts/sim.js` | จำลองการเล่นหลายพันเกมด้วยผู้เล่นหลายแบบ เพื่อเช็คความยากและความคุ้มของปุ๋ยแต่ละสูตร |
| `scripts/smoke-test.js` | ทดสอบเล่นจริงใน browser ขนาดมือถือครบทุกฤดู ล้มเหลวถ้ามี error และบันทึกภาพหน้าจอ |
| `scripts/build-artifact.js` | รวมทุกไฟล์เป็นไฟล์เดียว `dist/the-magic-farmcare.html` |
| `js/share.js` | วาดการ์ดแชร์ผลคะแนน และรูปพรีวิวลิงก์ |
| `js/cover.js` | ภาพปกหน้าแรก 160x120 จุด แบบเกมยุค 90 สีตาม CI: แปลงเกษตรมุมเฉียงลอยกลางฟ้า แถวผักสีเขียวกับนาข้าวสีทอง เถียงนามุงหญ้า โอ่งน้ำ แปลงลอยขึ้นลง เมฆลอย ลมพัดพืช (ภาพนิ่งถ้าเครื่องตั้งให้ลดการเคลื่อนไหว) |
| `img/og-image.png` | รูปพรีวิวเวลาส่งลิงก์ใน LINE / Facebook |
| `scripts/make-og-image.js` | สร้าง `img/og-image.png` ใหม่ (รันเมื่อแก้ฉากหรือโลโก้) และบันทึกตัวอย่างการ์ดยศทุกระดับได้ |
| `scripts/render-music.js` | อัดเพลงพื้นหลังเป็นไฟล์ WAV ไว้ฟังตัวอย่างโดยไม่ต้องเล่นเกม |

## คำสั่งสำหรับนักพัฒนา

```bash
npm run sim              # เช็คสมดุลเกม (ผู้เล่นแบบต่างๆ ตามตารางข้างล่าง)
FERTS=1 npm run sim      # แสดงเพิ่มว่าใช้ปุ๋ยสูตรไหนบ่อยแค่ไหน และเก็บเกี่ยวบนดินเปรี้ยวกี่ %
NOACID=1 npm run sim     # ปิดผลของดินเปรี้ยว ไว้วัดว่าเสียไปเท่าไหร่
npm run build:artifact   # สร้างไฟล์เดียวใน dist/ (สำหรับลิงก์ claude.ai)
npm test                 # เล่นทดสอบใน Chromium (ต้องมี playwright; ระบุ CHROMIUM_PATH ได้ถ้าใช้ Chromium ที่ติดตั้งเอง)
NODE_PATH="$(npm root -g)" node scripts/make-og-image.js [โฟลเดอร์ตัวอย่างการ์ด]
NODE_PATH="$(npm root -g)" node scripts/render-music.js music.wav [วินาที]
```

ผล `npm run sim` ปัจจุบัน (2,000 เกมต่อแบบ, 1 ปี, มีผักและแปลงริมโขง):

| ผู้เล่น | เงินเฉลี่ยตอนจบ | ดาวที่ได้ส่วนใหญ่ |
|---|---|---|
| เล่นเก่ง (เลือกพืชที่กำไรดีที่สุดทุกแปลง ปุ๋ยตรงธาตุที่ขาด ยาถูก ป้องกันโรคตั้งแต่ปลูก) | ~73,900 | 3 ดาว (100%) |
| เล่นเก่ง และเลือกปุ๋ยคุ้มที่สุดจากทั้ง 9 สูตร (`fertopt`) | ~76,300 | 3 ดาว (100%) |
| เล่นเก่ง แต่แต่งหน้า 21-0-0 ทุกแปลงทุกฤดู ไม่แก้ดินเปรี้ยว (`as21`) | ~56,300 | 2 ดาว (63%), 1 ดาว (37%) |
| แบบเดียวกัน แต่ใส่ปูนโดโลไมท์เมื่อดินเริ่มเปรี้ยว (`as21lime`) | ~59,900 | 2 ดาว (81%), 3 ดาว (8%) |
| เล่นพอใช้ (เลือกพืชเก่ง แต่ใช้ยาผิดบ้าง ข้ามปุ๋ยบ้าง ไม่ป้องกันโรค) | ~60,000 | 2 ดาว (50%), 3 ดาว (26%) |
| ปลูกข้าวอย่างเดียว ไม่ใส่ปุ๋ย ไม่ใช้ยา | ~34,000 | 0 ดาว |
| สุ่มเลือก | ~26,000 | 0 ดาว |

## ปุ๋ยในเกม

เลือกปุ๋ยตามธาตุที่ดินขาด ไม่ใช่ตามชนิดพืช ในหน้าเลือกแปลง ใต้แถบ N P K จะบอกว่ายังขาดธาตุไหนเท่าไหร่

| สูตร | ใช้เมื่อ | ช่วงที่เหมาะ | ธาตุที่ได้ต่อถุงในเกม | ราคาในเกม (บาท) |
|---|---|---|---|---|
| 16-20-0 | ขาด P เป็นหลัก ขาด N เล็กน้อย K พอแล้ว | รองพื้น | N12 P16 | 490 |
| 30-20-0 | ขาดทั้ง N และ P แต่ K พอแล้ว | รองพื้น | N24 P16 | 620 |
| 15-15-15 | ขาด N P K พอๆ กัน | ทุกช่วง | N12 P12 K12 | 550 |
| 20-8-8 | ขาด N เป็นหลัก ขาด P K เล็กน้อย | ทุกช่วง | N16 P6 K6 | 490 |
| อินทรีย์ (มูลไก่อัดเม็ด) | ธาตุอาหารน้อย แต่ดินเสื่อมช้าลง และลดดินเปรี้ยวได้เล็กน้อย | รองพื้น | N6 P6 K6 | 230 |
| 46-0-0 ยูเรีย | ขาด N มาก (เงินเท่ากันได้ N มากที่สุด) | แต่งหน้า | N30 | 490 |
| 21-0-0 แอมโมเนียมซัลเฟต | ขาด N ไม่มาก ถุงถูกกว่ายูเรียราว 30% แต่ N ไม่ถึงครึ่ง เงินเท่ากันได้ N น้อยกว่า ใส่ติดกัน 2 ฤดูดินเปรี้ยว | แต่งหน้า | N14 | 340 |
| 25-7-7 | ขาด N และขาด P K นิดหน่อย | แต่งหน้า | N20 P5 K5 | 580 |
| 0-0-60 | ขาด K | แต่งหน้า | K30 | 440 |
| ปูนโดโลไมท์ (ปรับปรุงดิน) | ดินเปรี้ยว เพิ่มแคลเซียมและแมกนีเซียม | ใส่ตอนปลูก | - | 100 |

- ใส่ผิดช่วง (เช่น ปุ๋ยแต่งหน้าใส่ตอนปลูก) ได้ผลแค่ 60%
- ผลเก็บเกี่ยวบอกธาตุที่ขาดทุกตัวพร้อมสูตรที่ควรใช้ตามธาตุที่ขาดคู่กัน (`MF.NUTRIENT_FIX` ใน `js/data.js`)
- ธาตุต่อถุงในเกม: ปุ๋ยผสมได้ราว 0.8 เท่าของตัวเลขสูตร (ปัดลง) 46-0-0 และ 0-0-60 ได้ 30 ซึ่งเป็นมากที่สุดที่ถุงเดียวเติมได้ ส่วน 21-0-0 คิดเทียบยูเรียตาม % ไนโตรเจน (21 × 30/46 ≈ 14) เงินเท่ากันจึงได้ N น้อยกว่ายูเรีย เหมือนราคาจริง
- 21-0-0 คุ้มเมื่อดินขาด N ไม่มาก (ไม่เกินราว 14) ถ้าขาดมากต้องใช้ยูเรีย ใน `npm run sim` ผู้เล่นที่เลือกปุ๋ยคุ้มที่สุดใช้ 16-20-0, อินทรีย์, 20-8-8, 30-20-0 และ 21-0-0 ตามธาตุที่ขาด ไม่มีสูตรไหนดีที่สุดทุกกรณี
- 25-7-7 ถุงแพงกว่ายูเรียแต่ได้ N น้อยกว่า เป็นปุ๋ยที่สะดวก (ได้ P K นิดหน่อยในถุงเดียว) แต่คุ้มน้อยกว่า ในกรณีที่ใกล้ที่สุดเสียเปรียบตัวเลือกที่ดีที่สุดราว 13-110 บาท เหมือนราคาจริงที่ N จาก 25-7-7 แพงกว่าจากยูเรีย

### ดินเปรี้ยวจาก 21-0-0

- แต่ละแปลงมีค่าความเปรี้ยวของดิน (`acid` เริ่มที่ 0) ฤดูไหนแปลงได้ 21-0-0 (รองพื้นหรือแต่งหน้า) จะเพิ่ม 2 และมีผลกับการเก็บเกี่ยวฤดูนั้นเลย
- ตั้งแต่ 4 ขึ้นไป (ใส่ติดกัน 2 ฤดู) ดินเปรี้ยว: พืชใช้ฟอสฟอรัสได้แค่ 70% และผลผลิตลดอีก 5% ตั้งแต่ 6 (3 ฤดู) ใช้ P ได้ 55% ผลผลิตลด 8% สูงสุด 8 ในดินกรดจัด P ถูกเหล็กและอะลูมินัมตรึงไว้ พืชดูดไปใช้ไม่ได้
- ปูนโดโลไมท์ใส่ตอนปลูก ลด 6 ทันทีก่อนพืชโต ปุ๋ยอินทรีย์และปอเทืองลด 1 หลังจบฤดู ถ้าสลับไปใช้ยูเรีย ดินจะไม่เปรี้ยวเพิ่ม
- ตัวเลขทั้งหมดอยู่ที่ `MF.ACIDITY` และ `MF.AMENDMENTS` ใน `js/data.js` แปลงจะมีป้าย "ดินเริ่มเปรี้ยว" / "ดินเปรี้ยว" ตัวเลือกปูนโดโลไมท์ขึ้นในหน้าเลือกแปลงเมื่อดินเริ่มเปรี้ยว
- เกมที่บันทึกไว้ก่อนมีระบบนี้เล่นต่อได้ ค่า `acid` ที่ไม่มีนับเป็น 0
- `NOACID=1 npm run sim` ปิดผลของดินเปรี้ยว ไว้เทียบว่าเสียไปเท่าไหร่: แบบ `as21` ได้ ~60,700 ถ้าไม่มีผลดินเปรี้ยว จริงได้ ~56,300 (เสียราว 4,400 บาท) ใส่โดโลไมท์แล้วได้ ~59,900 ส่วนต่างที่เหลือคือค่าปูน (8 ถุง × 100 บาท)

### ราคาปุ๋ยในเกม

ราคาในเกมไม่ใช่ราคาขายจริงของร้าน แต่ "สูตรไหนแพงหรือถูกกว่ากันราวเท่าไหร่" ตามสัดส่วนราคาเฉลี่ยร้านค้าในไทย ทุกรายการใช้หลักเดียวกัน:

- ราคาในเกม = ราคาปลีกเฉลี่ยต่อกระสอบ 50 กก. ÷ ราคาปลีกยูเรียเฉลี่ย × ราคายูเรียในเกม 490 แล้วปัดเป็นหลักสิบ
- ราคาปลีกยูเรียเฉลี่ย 979 บาท/50 กก. (ปี 2569 จากรายงานราคาปุ๋ยของสำนักงานพาณิชย์จังหวัด 6 จังหวัด และร้านค้า 1 แห่ง)
- ถ้าแหล่งเดียวกันมีราคายูเรียด้วย ใช้สัดส่วนในแหล่งนั้น (จับคู่) แล้วเฉลี่ยทุกแหล่ง ถ้าไม่มี หารด้วยยูเรียเฉลี่ย 979 บาท

| รายการ | ราคาปลีก ÷ ยูเรีย | ข้อมูลราคาปลีก | ราคาในเกมเดิม | ราคาในเกมใหม่ |
|---|---|---|---|---|
| 46-0-0 | 1.00 | 979 บาท | 490 | 490 |

- ราคาปลีกห่างกันน้อยกว่าราคาวัตถุดิบ เพราะค่าขนส่งและค่าดำเนินการต่อถุงพอๆ กันทุกสูตร
- ถ้าจะปรับราคาใหม่ ให้หาราคาปลีกเฉลี่ยใหม่ คำนวณตามสูตรข้างบน แล้วแก้ `cost` ใน `MF.FERTS` และ `MF.AMENDMENTS` (`js/data.js`) แล้วรัน `npm run sim` เช็คสมดุล

## หมายเหตุเรื่องความรู้ในเกม

ชื่อปุ๋ยและสารเคมีใช้ชื่อสามัญหรือสูตร ไม่ใช้ชื่อการค้าหรือยี่ห้อในเกม ราคาปุ๋ยเทียบสัดส่วนจากราคาเฉลี่ยร้านค้าในไทย (ดูหัวข้อราคาปุ๋ยในเกม) แต่ตัวเลขผลผลิต ราคาขายพืช เมล็ดพันธุ์ และยาถูกปรับเพื่อความสนุก ไม่ใช่ราคาตลาดจริง
