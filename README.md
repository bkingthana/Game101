# The Magic Farmcare

เกมวางแผนการเกษตรแบบ Pixel art เล่นผ่าน browser บนมือถือ ไม่ต้องติดตั้ง
นำเสนอโดย ธนาพันธ์ ฟาร์มแคร์

**เล่นออนไลน์:** https://the-magic-farmcare.vercel.app

## วิธีเล่น

- เริ่มด้วยทุน 20,000 บาท เล่น 1 ปี (3 ฤดู: ฝน / หนาว / ร้อน) จบในราว 5 นาที
- ฟาร์มมี 4 แปลง ดินและภูมิประเทศต่างกัน (ที่ลุ่ม, ที่ดอน, ดินร่วน, ริมโขงดินตะกอน) ฉากเป็นแม่น้ำโขงและทิวเขาฝั่งลาวแบบนครพนม
- แปลงริมโขงสูบน้ำได้ถูก แต่หน้าฝนน้ำโขงขึ้นท่วมพืชที่ไม่ทนน้ำ (ผักบุ้งและข้าวทนได้)
- 1 ฤดูมี 3 ช่วง
  1. **เตรียมปลูก**: ดูพยากรณ์อากาศ เลือกพืช (ข้าว / ข้าวโพดเลี้ยงสัตว์ / หอมแดง / ผักบุ้ง / คะน้า / ผักชีลาว / พักดินหว่านปอเทือง / ปล่อยว่าง) และปุ๋ยรองพื้น
  2. **ดูแล**: เจออากาศจริง แมลง โรค วัชพืช ต้องเลือกยาให้ถูก และใส่ปุ๋ยแต่งหน้า
  3. **เก็บเกี่ยว**: ขายผลผลิต ดูสรุปว่าอะไรทำให้ผลผลิตลดลง
- ผักกินใบที่ไม่ใช้ยาเคมี หรือใช้ชีวภัณฑ์ (เชื้อบีที ไตรโคเดอร์มา) ขายเป็นผักปลอดภัย ได้ราคาเพิ่ม 15%
- ได้ดาวตามเงินตอนจบ: 1 ดาว 45,000 / 2 ดาว 55,000 / 3 ดาว 65,000 บาท
- ความยาวเกมและเป้าดาวตั้งได้ที่ `MF.CONFIG` ใน `js/data.js` (`years`, `stars`)
- ถ้าเงินเหลือไม่ถึง 1,000 บาทตอนเริ่มฤดู จะล้มละลาย
- เกมบันทึกอัตโนมัติในเครื่อง ปิดแล้วกลับมาเล่นต่อได้

## เปิดเล่นในเครื่อง

ดับเบิลคลิก `index.html` เปิดด้วย Chrome / Safari ได้เลย (ต้องต่อเน็ตเพื่อโหลด font)

## การอัปเดตเว็บ (Vercel)

- เว็บอยู่ที่โปรเจกต์ `the-magic-farmcare` ใน Vercel ของ BK เป็นไฟล์ static ที่ root ของ repo ไม่มีขั้นตอน build
- ตอนนี้ยังไม่ได้ติดตั้ง Vercel GitHub app การ push code จึง **ไม่** อัปเดตเว็บอัตโนมัติ ต้องสั่ง deploy ใหม่จาก branch นี้ทุกครั้ง (ให้ Claude ทำผ่าน Vercel connector ได้)
- ถ้าอยากให้อัปเดตเองทุกครั้งที่ push: ติดตั้ง Vercel app บน GitHub แล้วเชื่อมโปรเจกต์กับ repo `bkingthana/Game101` ในหน้า Settings > Git ของโปรเจกต์
- `.vercelignore` กันไม่ให้ไฟล์เครื่องมือนักพัฒนา (scripts/, dist/) ขึ้นเว็บ

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ |
| `css/style.css` | หน้าตาและสี |
| `js/data.js` | ข้อมูลเกมทั้งหมด: พืช ปุ๋ย ยา ศัตรูพืช ราคา สภาพอากาศ บทพูดลุงพันธ์ **แก้ตัวเลขสมดุลเกมที่นี่** |
| `js/engine.js` | กติกาและการคำนวณผลผลิต (ไม่เกี่ยวกับหน้าจอ) |
| `js/sprites.js` | ภาพ Pixel art ทั้งหมด วาดเป็นตัวอักษรทีละจุด |
| `js/scene.js` | ฉากฟาร์มเคลื่อนไหว (ป้ายธนาพันธ์ ฟาร์มแคร์ ต้นมะพร้าว สระน้ำ ฝน หมอก) |
| `js/audio.js` | เพลงและเสียงเอฟเฟกต์ 8-bit สร้างด้วย code |
| `js/ui.js` | หน้าจอ ปุ่ม บทสอน การบันทึกเกม |
| `img/logo-thanapun-dark.png` | โลโก้ธนาพันธ์ ฟาร์มแคร์ แบบตัวหนังสือสีขาวสำหรับพื้นเข้ม (ตาม color guide) |
| `scripts/sim.js` | จำลองการเล่นหลายพันเกม เพื่อเช็คความยาก |
| `scripts/smoke-test.js` | ทดสอบเล่นจริงใน browser ครบทุกฤดู |
| `scripts/build-artifact.js` | รวมทุกไฟล์เป็นไฟล์เดียว `dist/the-magic-farmcare.html` |

## คำสั่งสำหรับนักพัฒนา

```bash
npm run sim              # เช็คสมดุลเกม (ผลของผู้เล่นแบบเก่ง / พอใช้ / มั่ว)
npm run build:artifact   # สร้างไฟล์เดียวใน dist/ (สำหรับลิงก์ claude.ai)
npm test                 # เล่นทดสอบใน Chromium (ต้องมี playwright)
```

ผล `npm run sim` ปัจจุบัน (2,000 เกมต่อแบบ, 1 ปี, มีผักและแปลงริมโขง):

| ผู้เล่น | เงินเฉลี่ยตอนจบ | ดาวที่ได้ส่วนใหญ่ |
|---|---|---|
| เล่นเก่ง (เลือกพืชที่กำไรดีที่สุดทุกแปลง ปุ๋ยตรงธาตุที่ขาด ยาถูก) | ~74,000 | 3 ดาว (99%) |
| เล่นพอใช้ (เลือกพืชเก่ง แต่ใช้ยาผิดบ้าง ข้ามปุ๋ยบ้าง) | ~60,000 | 2 ดาว (50%), 3 ดาว (25%) |
| ปลูกข้าวอย่างเดียว ไม่ใส่ปุ๋ย ไม่ใช้ยา | ~34,000 | 0 ดาว |
| สุ่มเลือก | ~26,000 | 0 ดาว |

## หมายเหตุเรื่องความรู้ในเกม

ชื่อปุ๋ยและสารเคมีใช้ชื่อสามัญ ไม่ใช้ชื่อการค้า ตัวเลขผลผลิต ราคา และต้นทุนถูกปรับเพื่อความสนุก ไม่ใช่ราคาตลาดจริง
